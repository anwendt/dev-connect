# dev-connect v0.3.0 Release Notes

## Overview

`v0.3.0` improves tunnel resilience for enterprise proxy environments and
formalizes Apache-2.0 licensing across the repository.

This release is intended for environments where `kubectl port-forward` streams
can be interrupted by proxies, firewalls, or long-running idle network paths.

## Highlights

- Added a background tunnel supervisor for `connect`.
- Added automatic restart of the `kubectl port-forward` process when reconnect
  is enabled.
- Added supervisor readiness signaling before the client reports a prepared
  session.
- Added supervisor log capture for tunnel stdout and stderr.
- Improved disconnect cleanup by terminating the recorded process tree/process
  group on supported operating systems.
- Added Apache-2.0 SPDX headers to supported source, manifest, workflow, and
  documentation files.
- Replaced `LICENSE` with the official Apache License, Version 2.0 text.
- Added `NOTICE` with project copyright and third-party dependency notices.
- Updated Helm chart metadata to `0.3.0`.

## Compatibility

- Existing `dev-connect/v1` client configuration remains compatible.
- Existing gateway deployments do not require a protocol change.
- The gateway remains a TCP-only forwarder and does not perform SSH
  authentication.

## Security Notes

- No SSH credentials are stored in Kubernetes.
- No Kubernetes/Rancher API client libraries are introduced.
- Kubernetes access remains delegated to the local `kubectl` process.
- Host key pinning remains mandatory.
- The new supervisor logs tunnel process metadata and output required for
  troubleshooting; it does not log SSH session contents.

## Operational Notes

- Automatic reconnect remains enabled by default unless `--no-reconnect` or the
  equivalent configuration disables it.
- For proxy-heavy environments, keepalive settings from `v0.2.1` should remain
  enabled together with the new supervisor.
- Operators should review `supervisor.log` in the dev-connect session directory
  when diagnosing repeated tunnel restarts.
